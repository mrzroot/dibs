PROJECT WALKTHROUGH

See and recover a human edit without discarding unrelated agent changes.

  1. Check the integration first

    Use a disposable Git checkout. Run init for your agent, then inspect which hooks are active; hook support varies by tool.

    dibs init
dibs doctor

  2. Inspect what changed

    Change a line by hand, then ask the agent to make an unrelated edit. Look for attributed edits and reverts rather than assuming every shell edit was blocked.

    dibs status

  3. Preview before restoring

    Check which lines would be recovered. Apply the restore only after reviewing that preview; --whole is not necessary for recovering individual edits.

    dibs restore app.py --dry-run
راهنمای عملی پروژه

ویرایش خودتان را بدون حذف تغییرهای نامرتبط دستیار بررسی و بازیابی کنید.

  1. اول بررسی اتصال

    در یک نسخهٔ آزمایشی مخزن، اتصال ابزار را بررسی کنید؛ پشتیبانی قلاب‌ها در دستیارهای مختلف یکسان نیست.

    dibs init
dibs doctor

  2. مشاهدهٔ تغییرها

    یک خط را دستی تغییر دهید و از دستیار بخواهید تغییر دیگری انجام دهد؛ انتساب و گزارش بازگردانی را بررسی کنید.

    dibs status

  3. پیش‌نمایش بازیابی

    اول مشخص کنید کدام خط‌ها برمی‌گردند؛ برای چند خط نیازی به بازگردانی کل فایل نیست.

    dibs restore app.py --dry-run
